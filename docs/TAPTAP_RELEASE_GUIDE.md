## 四、构建与接入

### 1. 小游戏包

```bash
bun install
bun run lint
bun run build:minigame
# 产物：dist-minigame/
```

`--mode minigame` 会关闭 PWA Service Worker，并使用相对路径 `base: './'`，避免平台容器缓存与子路径问题。

### 2. 广告位

复制 `.env.minigame`，填入 Dirichlet 创建的广告位：

```bash
VITE_TAPTAP_REWARDED_AD_UNIT_ID=...
VITE_TAPTAP_INTERSTITIAL_AD_UNIT_ID=...
bun run build:minigame
```

未配置广告位时，正式包不展示广告入口、不发放广告奖励；开发环境（`bun run dev`）会模拟 900ms 激励视频用于联调。

### 3. 已接入的平台能力

| 能力 | 代码位置 | 说明 |
| --- | --- | --- |
| TapTap 登录 | `src/platform/tap.ts` | 隐私授权后静默 `tap.login()`，不依赖服务端 |
| 云存档 | `src/platform/tap.ts` | 65s 节流单飞，`auto_save` 槽位；首启无本地档时自动恢复 |
| 平台隐私授权 | `src/components/PrivacyConsent.tsx` | 小游戏内优先 `tap.requirePrivacyAuthorize`；拒绝可仅本地游玩 |
| 激励视频 | `src/components/AdRewardButton.tsx` | 离线翻倍、每日宝箱、广告免费洗练、灵石加速（`×2`/10 分钟，每日 5 次）；仅 `isEnded` 发奖 |
| 插屏 | `src/components/Modals.tsx` | 胜利结算关闭后的自然断点，3 分钟冷却 |
| 添加到桌面 | `src/components/Modals.tsx` | `tap.hasHomeScreenWidgetAndPinned` / `tap.createHomeScreenWidget` |
| 生命周期存档 | `src/stores/useGameStore.tsx` | `visibilitychange` / `pagehide` / `tap.onHide` 落盘 |

### 4. 广告设计原则

- 只做“加速器”，不做“收费站”：离线翻倍、每日 3 神晶 + 5 词缀石、每日 3 次免费洗练、胜利插屏。
- 不做 Banner，不遮挡战区；插屏仅在结算关闭后，≤1 次/3 分钟。
- 不做抽卡、盲盒、体力、扫荡券、站外充值；不写“看广告必得 SSS”。

## 六、仍需运营主体完成

1. 注册并认证 TapTap 开发者，创建小游戏，取得 App ID。
2. 办理软著（原始取得）与小游戏前置备案；准备 ICP 备案。
3. 在 Dirichlet 创建激励/插屏广告位，回填 `.env.minigame`。
4. 将 `public/privacy.html`、`public/terms.html` 中的占位符替换为真实主体信息，部署后把 URL 填入后台。
5. 用 TapTap 打包工具上传 `dist-minigame/`，完成自动化测试、自测、提审。

> 若后续要做内购，必须先取得 ISBN 版号，且版号主体与运营主体一致；当前版本不要出现任何付费入口。
