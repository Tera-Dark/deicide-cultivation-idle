## 三、开发与发布包装参考

1. **H5 / PWA 离线直玩模式（TapTap 试玩 / 自有域名）**：
   - 根路径部署命令：`VITE_BASE_PATH=/ npm run build`
   - 已内置 `vite-plugin-pwa` 自动生成 `manifest.webmanifest` 与离线缓存 `sw.js`，全量使用本地系统字体栈（无任何海外 CDN 外链阻塞国内网络）。
   - 游戏序章底部与系统设置内已内置《适龄提示 12+》《健康游戏忠告》及《用户协议与隐私政策》（纯单机不联网、零隐私采集）。
2. **Android APK（Capacitor / WebView 封装用于 TapTap 端内安装包提审）**：
   - 将 `VITE_BASE_PATH=./` 构建后的 `dist/` 目录注入 Capacitor Android 工程的 `android/app/src/main/assets/public/`。
   - 应用图标直接使用 `public/taptap/icon-1x1.jpg` 生成各 DPI `ic_launcher`；开屏启动图可裁切使用 `public/taptap/poster-3x4.jpg`。
   - 数据默认持久化在客户端 WebView `localStorage`，且设置内自带 Base64 存档导入导出与 `.json` 存档文件备份下载，卸载或换机可无损迁移进度。
