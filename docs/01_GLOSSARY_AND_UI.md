# 01. 全局名词解析与 UI 规范 (Glossary & UI - v4.1)

## 一、 全局简化名词与资源字典
所有 UI 显示与代码变量命名严格遵循以下标准，确保玩家零理解成本：

| 显示名称 | 代码变量名 | 数据类型 | 重开/通关时持久性 | 获取途径与核心用途 |
| :--- | :--- | :--- | :--- | :--- |
| **灵石** | `spiritStones` | `Decimal` | **局内重置 (归零)** | **主货币**。造成伤害即实时获得（无需打死BOSS）。用于提升主角顿悟成长率、突破肉身境界、升级主动神通、购买机关傀儡及升级 5 大本命佣兵。 |
| **词缀石** | `affixStones` | `number` | **永久保留** | **打造货币**。按【劫数 × 躯壳深度】掉落：每重躯壳期望 = 本劫 `stonePerShell` × 深度权重（劫一每重 `0.4` 颗 → 劫十每重 `2.0` 颗，整数必掉、小数按概率补），全通一局约 `4`（劫一）~ `20`（劫十）颗。用于洗练佣兵的 **10 个等级词缀槽（Lv.10 ~ Lv.1000）**（阶梯 `2 / 4 / 7 / 12`）与【道纹淬炼】（`8 / 25 / 70 / 220` 必定提升一阶）。 |
| **神晶** | `divineCrystals` | `Decimal` | **永久保留** | **终局核心货币**。彻底击败BOSS（打穿第10重躯壳）时结算掉落。用于**解锁2~5号位本命佣兵**、洗练佣兵的**★先天本命神通槽**、以及抽取与升级【古神遗物】。 |
| **道力** | `mana` | `number` | **局内重置 (开局40点)**| **技能能量**。初始上限 100点，开局默认 `40` 点。每秒自然恢复 `1.0` 点，且**每次手动点击额外恢复 `0.8` 点**。用于释放主角的 4 大主动神通。 |
| **点击层数** | `clickStacks` | `Decimal` | **局内重置 (归零)** | **成长计数**。本局内主角累计有效点击次数（含手动、自动傀儡、分身残影），用于检测肉身破境条件与触发佣兵联动。 |

## 二、 核心重开与传承铁律
1. **主动【重开】**：当玩家因策略失误或遇到瓶颈时，可随时点击顶部【重开】按钮。**中途重开不结算任何【神晶】奖励**，但本局中途打破躯壳已拿到的【词缀石】永久保留！
2. **状态重置范围**：重开或通关进入下一难度时，BOSS血量重置为第1重躯壳、灵石归零（若有先天灵根遗物则重置为初始值）、主角境界/顿悟/神通/傀儡等级归零、当前累积点击修为（`accumulatedAtk`）重置（若有逆时沙漏遗物则设为初始值）、**已解锁佣兵的局内等级（Level）重置为 1 级**。
3. **永久传承范围**：玩家已拥有的【词缀石】、【神晶】、【遗物等级】、**已解锁的 1~5 号本命佣兵**、**已开启的词缀槽位洗练权**，以及 **每个佣兵身上已洗出的【★本命词缀】和【10个等级词缀】100% 永久保留！**（局内升到对应槽位等级即自动点亮生效）。

## 三、 UI 界面布局规范（严格保持现有极简暗黑矢量 UI）
* **三段式竖屏布局**：
  1. **顶部状态栏**：第一行左侧为【劫数下拉切换按钮】、中间为【计时器】、右侧为【重开】与【设置】按钮；第二行为【灵石、词缀石、神晶】三大资源栏。
  2. **中部主战区**：上方为当前躯壳阶段名、总 DPS 与主血条（含10个阶段小格）；中央为旋转几何古神法相与环绕的佣兵伴飞图标；下方为【道力进度条】与【4大主动神通释放按钮】。
  3. **底部构筑区（3个Tab + 倍率切换器）**：包含【主角修为】、【五人佣兵】、【古神遗物】三个页签，右侧配 `[ ×1 | ×10 | MAX ]` 批量购买切换器。
