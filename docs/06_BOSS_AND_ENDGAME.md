# 06. BOSS 10重躯壳、10大劫数独立掉宝与无感轮回 (BOSS & Endgame - v4.1)

> **48 小时平滑刷宝节奏与解锁破禁规则**：
> 1. **告别开局秒杀，平滑中后期数值**：【劫数一】总血量设定为 **`250,000 (25万)`**；从【劫数五】起至【终焉劫（劫十）】对血量梯度与遗物增幅进行平滑配平，避免跨过第 5 劫后“无脑平推”，需要反复刷印、搭配词缀与圣/仙遗物方能稳步破禁。
> 2. **双门坎渐进破禁（刷宝闭环）**：解锁劫数 `N`（`2..10`）需同时满足 **「前劫通关次数 ≥ unlockReqPrevClears」** 与 **「遗物圣殿总等级 ≥ unlockReqRelicLevels」**，鼓励玩家在当前最适劫数刷满遗物与神晶后再冲击下一重劫境。
> 3. **线性掉落件数 + 独立阶位掉率（神阶劫十专属 1%）**：从劫一（`1 件`）到劫十（`10 件`）**每次通关掉落遗物数量严格呈线性增长（`1 ~ 10` 件）**，且每个劫数拥有**独立配置的阶位概率表**；所有低阶遗物全程保留不直接淘汰（权重逐步降低），而至高 **【神】阶遗物仅在终焉劫（劫十）以 `1%` 默认概率掉落**。
> 4. **无感自动结算与 `0.25s` 连刷**：支持全局【无感自动结算】设置（默认开启）与 SSS 解锁的 `0.25s` 无感连刷；常规重刷与连刷时不再弹出全屏结算遮挡，改为战区底栏静默条展示摘要，不打断洗练词缀与精炼遗物的操作流！
> 5. **BOSS 回血安全锁**：劫数五、九、十的 BOSS 每秒百分比回血，**上限严格锁定在当前这一重躯壳的最大血量**，绝不会倒退复活已击碎的躯壳。

### 词缀石掉落模型（v3.8 经济重配）

```
单次击破期望 = 本劫 stonePerShell × (baseAffixStones / 4) × (1 + 遗物/词缀加成%)
抽成整数   = 整数部分必掉，小数部分按概率补 1 颗（例如 0.4 颗 = 40% 掉 1 颗）
```

## 三、 通关竞速（Speedrun）评级与无感自动连刷
击败 Phase 10 时，根据本局耗时 `elapsedSeconds` 乘算最终神晶奖励：
```ts
FinalCrystals = BaseCrystals
  * SpeedMult
  * (tribulationId === 'tier_10' ? 2 ^ ngPlusCount : 1) // 实为通关前计数的 2^ngPlusCount
  * (1 + 0.08 * L_rel_s_crystal_bless + 0.12 * L_rel_e_inf_crystal + 0.20 * L_rel_m_god_crystal)
```
* **C 级（苦战）**：耗时 `>= 1800秒 (30分钟)`，神晶 `×1.0`
* **B 级（破敌）**：耗时 `< 1800秒`，神晶 `×1.5`
* **A 级（神速）**：耗时 `< 600秒 (10分钟)`，神晶 `×2.0`
* **S 级（雷霆）**：耗时 `< 180秒 (3分钟)`，神晶 `×3.5`（劫 9~10 额外 `+1` 件遗物掉落）
* **SSS 级（瞬杀降维）**：耗时 **`< 15秒`**，神晶 `×6.0`（劫 9~10 额外 `+1` 件遗物掉落），且该劫数永久解锁**【`0.25s` 无感自动连刷】**开关（战区右上与劫数弹窗均可一键切换）。
