# 04. 五大固定本命佣兵、1000级十词缀体系与48词缀全表 (Mercenaries & 48 Affixes - v4.1)

> **核心设计规范**：
> 1. **5大固定本命佣兵（指数级定位阶梯）**：1号~5号位固定为 **5 位拥有独特流派机制的专精护法**！前 3 位专精各自输出流派，4 号位专精经济与冷却光环，**5 号位直接统御全队带来复利指数级增幅**！
> 2. **防套娃递归铁律（防浏览器卡死）**：【残影连击 `af_t2_double`】、【三才剑阵 `af_t2_triple`】、1号位天赋①【剑影分光】及本命神通 ★【万剑归宗 `sp_sword_storm`】产生的**额外攻击，严禁再次触发连击/三才/剑影分光**；但每次额外攻击均可正常触发一次**攻击层**效果（充能/装填/横财/反哺），其多段命中也可独立触发**命中层**效果（毒爆/催熟/天罚）！
> 3. **★【神通法相 (`sp_skill_trig`)】边界说明**：每攻击30次自动免费触发 1 次【天罚神雷】时，若主角尚未破境至金丹期，则按技能 Lv.1 的倍率直接释放，不受解锁限制。
> 4. **同名词缀叠加与保留规则**：10 个等级槽位中允许刷出多个相同词缀并相加（【缩资减耗】单个佣兵最多减免 `75%`，触发概率类词缀上限 `100%`；而【寻宝天眼 `af_t2_stone_p`】与【贪婪触须】叠加超过 `100%` 时，每满 `100%` 必掉 `+1` 词缀石，余数再做概率判定！）。所有词缀在重开时 **100% 永久保留**！

### 洗练锁定、品质权重（受七彩神石加成）与保底规则
* **单槽重铸 vs 批量洗练（v3.8 阶梯定价）**：点击已开启槽位右侧的**【单槽洗练】**只洗该槽位，消耗按槽位阶梯 `2 / 2 / 2 / 4 / 4 / 4 / 7 / 7 / 7 / 12` 颗（对应 `Lv.10 ~ Lv.1000`）；**首次通关【劫数二】后解锁【批量槽位锁定】功能**，可勾选锁定满意槽位后批量洗练未锁定槽位，每个未锁槽位按 `1 / 1 / 1 / 2 / 2 / 2 / 3 / 3 / 3 / 5` 颗计价（批量单槽更便宜，但**不享受【命运骰子】免单**）。
* **【道纹淬炼】（v3.8 新增）**：已洗出的词缀可消耗词缀石**必定提升一阶**，是终局的确定性沉淀池：

| 阶段 | 消耗 |
| :--- | :--- |
| 凡品 → 良品 | `8` 颗 |
| 良品 → 上品 | `25` 颗 |
| 上品 → 极品 | `70` 颗 |
| 极品 → 仙品 | `220` 颗 |
| 仙品 | 已达上限，不可淬炼 |

  淬炼只改变品质阶，**不改变词缀种类**（想换种类仍需洗练）；空槽位不能淬炼，需先洗出一条基础词缀。单槽由凡淬满仙品共 `323` 颗，四人 40 槽全部淬满约 `12,920` 颗（≈ `646` 次劫十全通）。
* **先看后换预览**：任何洗练均生成候选结果，支持玩家点击 **【替换】** 或 **【保留原词缀】**。
* **五阶品质权重与倍率 (`tierMult`)**：
  * 凡品 (白)：权重 `35`，倍率 `×1.0`
  * 良品 (绿)：权重 `30`，倍率 `×1.6`
  * 上品 (蓝)：权重 `20`，倍率 `×2.5`
  * 极品 (紫)：权重 `11 * (1 + 0.08 * L_rel_e_affix_luck)`，倍率 `×4.0`
  * 仙品 (金)：权重 `4 * (1 + 0.08 * L_rel_e_affix_luck)`，倍率 `×7.0`
* **10抽气运保底**：每累计点击洗练 10 次（无论替换还是放弃，**神晶本命洗练不计入或单独不触发**），第 10 次必出 极品(紫, 80%) 或 仙品(金, 20%)，随后重置气运值！
