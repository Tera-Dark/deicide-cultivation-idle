# 07. 视觉与交互规范：暗黑矢量 UI、手机优先触控与性能护航 (Visual & UX - v4.1)

> **致 AI 开发者（UI 保护最高指令）**：
> 1. **保持既有暗黑矢量美学**：延续深邃暗黑背景（`#090a10`）、细边框深色卡片（`#12151f`）、青蓝高亮按钮以及简洁线性 SVG 矢量图标，100% 保持干净直观的信息层级。
> 2. **全局零 Emoji 规范**：所有图标均采用 `lucide-react` 或定制线性 SVG 组件。
> 3. **手机端优先触控**：核心交互按钮保持 `44px+` 安全触控热区，底部弹窗采用移动友好抽屉式卡片与大字号排版。

## 一、 遗物六阶流光视觉分级 (`index.css` / `relics.ts`)
遗物严格保留单字阶位名称（**凡 / 灵 / 玄 / 圣 / 仙 / 神**），采用**统一无衬线主字体 (`--font-sans`)** 搭配渐层填充、辉光阴影与高阶流光动画来体现阶位压迫感（不切换花哨异体字）：
* **凡** (`font-tier-common`)：素白字色 + 微阴影
* **灵** (`font-tier-rare`)：翠绿渐层 + 柔绿辉光
* **玄** (`font-tier-mystic`)：天蓝渐层 + 冰蓝辉光
* **圣** (`font-tier-saint`)：玄紫渐层 + 紫韵辉光
* **仙** (`font-tier-epic`)：鎏金渐层 + `tier-sheen` 扫光动画 + 金芒辉光
* **神** (`font-tier-mythic`)：猩红鎏金双色渐层 + `tier-sheen` 扫光动画 + 烈焰红芒辉光

## 二、 高并发性能优化与无感结算体验 (`constants.ts` / `BossArena.tsx`)
为避免中后期高攻速、极速通关下频繁 DOM 重绘与弹窗打断玩家洗练词缀/精炼遗物：
1. **同屏弹出次数硬上限**：
   * 伤害飘字 (`MAX_ONSCREEN_FLOATING_TEXTS = 6`)：最短生成间隔 `85ms`，队列截断上限 `6` 条；
   * 点击波纹 (`MAX_ONSCREEN_RIPPLES = 4`)：最短生成间隔 `65ms`，同时存在最多 `4` 个波纹；
   * 破壳横幅 (`PHASE_BANNER_MIN_INTERVAL_MS = 300`)：单次批量破壳聚合为 `1` 条横幅，展示时长 `1500ms`；
   * Toast 轻提示 (`TOAST_DURATION_MS = 2200`)：同类消息 `1500ms` 节流防刷屏，自动连刷与无感模式中抑制 `Lv.1000` 重复提示。
2. **无感自动结算 (`silentAutoClear`)**：
   * 开启后，在**非首次破禁/系统解锁里程碑**的普通通关以及 `0.25s` 自动连刷中，**不再弹出全屏 `VictoryModal` 遮挡**；
   * 改为在战区底栏显示非阻断式极简战报条（耗时、评级、神晶与掉落数量），附带一键 **`[再战]`** 与 **`[详报]`** 按钮；
   * **首次解锁关键节点**（如首通劫一开遗物圣殿、首破劫二开锁槽、首次解锁下一劫或首次 SSS）仍自动弹出完整庆贺结算。

## 三、 五人佣兵与千级道纹对比预览 (`TabMercenaries.tsx` / `Modals.tsx`)
1. **五人佣兵卡片**：
   * 顶部行展示 `[线性SVG流派图标 + 名称 + Lv.等级 + 下一槽位解锁提示]`，右侧配 `44px+` 触控升级按钮与独立自动升级开关（劫六后解锁）；
   * 若佣兵攻击间隔超出 `25次/秒 (0.04s)`，于面板明显标注 **`25/s转攻×X.XX`** 倍率；
   * 底部 10 词缀槽紧凑网格清晰区分已生效（按品质着色）、已洗出未达级（半透明提示等级）与未开启状态。
2. **千级道纹洗练对比弹窗 (`MercForgeModal`)**：
   * 顶部独立展示 `★ 先天本命神通槽` + `神晶重铸 (5神晶)`；
   * 触发单槽/批量洗练或本命重铸后，底部弹出高亮 **前后对比预览条**：同步展示 **品质升降徽章**、**个人 DPS 增减百分比 (`+X.X% ↑` / `-X.X% ↓`)**、**全队 DPS 变化对比** 及 **新旧效果逐条高亮比对**，支持一键 `确认替换` 或 `保留原样`。
