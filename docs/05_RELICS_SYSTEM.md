# 05. 局外 45 件六阶遗物系统配置表 (Relics System - v4.1)

> **核心刷宝双轨制、六阶流光样式与防溢出闭环规则**：
> 1. **六阶体系（共 45 件）**：划分为 **【凡(8)、灵(9)、玄(8)、圣(7)、仙(7)、神(6)】** 六大稀有阶（仅保留单字称呼），对应 **素白 / 翠绿 / 幽蓝 / 玄紫 / 鎏金 / 猩红** 六种专属语义色、统一无衬线字体搭配渐层色、辉光与金属扫光动画（`.font-tier-common` ~ `.font-tier-mythic`）。未拥有某件遗物时（`总等级 === 0`），其所有增益值一律强制判定为 `0`（乘算类为 `1`）。
> 2. **劫数通关直掉与线性数量增长**：遗物**不再通过神晶抽卡获取**，而是通过反复通关【诸天劫数】直接掉落！劫 1 → 劫 10 每次通关掉落件数呈 **线性递增（1 件 → 10 件）**；每个劫数拥有**独立阶位掉率权重表**（参见 `06_BOSS_AND_ENDGAME.md`），其中**【神】阶仅在终焉劫(劫十)以默认 `1%` 概率掉落**；低阶位全程保留（权重随劫数递减），且可通过 **【天机寻宝盘 (`rel_y_drop_luck`)】** 与 **【造化仙冕 (`rel_e_rarity_crown`)】** 显著抬升高阶位掉率。
> 3. **双轨无限等级叠加 (`TotalLv = 神晶级 + 劫印级`)**：
>    - **神晶精炼等级 (`relicLevels`)**：受制于遗物的手动上限 `maxLevel`（如 `50 级`，部分核心遗物无上限 `∞`），消耗【神晶】手动强化。
>    - **通关劫印等级 (`relicDropLevels`)**：每次在劫数中重复掉落同一遗物时自动 `+1 劫印级`！绝大多数遗物**无劫印上限（无限叠加）**；少数数值防崩坏遗物（如减耗、降血、缩冷却、超百暴击、免材料、改时间类）设有专属 `maxDropLevel`。
>    - **满印溢转神晶机制**：若某件特限遗物的劫印已达 `maxDropLevel`，再次掉落时**直接按阶位基数折算为【神晶】奖励**，并同步享受 **【圣】阶及以上神晶增幅遗物**（圣灵聚晶塔 / 源初神格 / 古神铸晶炉）加成！

## 掉宝稀有度与神晶增幅公式 (`relics.ts` / `damageCalc.ts`)

1. **高阶掉宝幸运积分 (`DropRarityLuckScore`)**：
   ```ts
   luckScore = 0.12 * TotalLv(rel_y_drop_luck) + 0.25 * TotalLv(rel_e_rarity_crown);
   ```
   针对某个劫数配置 `relicDropWeights` 中 `baseW > 0` 的各阶位，令 `step = tierOrder - minOrderInTrib`：
   ```ts
   effectiveWeight = baseW * (1 + luckScore * step * 0.65);
   effectivePct = effectiveWeight / sum(effectiveWeight);
   ```
   *(注：仅在当前劫数合法掉落的阶位间重分配权重；越往高阶 `step` 越大，幸运加成越显著。)*

2. **【圣】阶及以上神晶获取总倍率 (`getRelicCrystalBonusMult`)**：
   ```ts
   CrystalBonusMult = 1
     + 0.10 * TotalLv(rel_s_crystal_bless)   // 圣：圣灵聚晶塔
     + 0.15 * TotalLv(rel_e_inf_crystal)     // 仙：源初神格
     + 0.25 * TotalLv(rel_m_god_crystal);    // 神：古神铸晶炉
   ```
   同时作用于 **劫数通关结算神晶** 与 **特限遗物满印溢转神晶**。
