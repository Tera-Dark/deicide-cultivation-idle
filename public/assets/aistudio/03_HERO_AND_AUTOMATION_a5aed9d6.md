# ⚡ 03. 主角成长体系、主动神通与前期提速 (Hero, Skills & Onboarding - v2.4终极封版)

> **黄金前 3 分钟留存设计（First 3-Minute Hook）**：
> 1. **开局即高潮**：每局开始时，主角默认拥有 **满值 `100/100` 道力**！新玩家进游戏第 1 秒就能直接按下 1 技能【燃血叩击】，体验刀刀暴涨的快感！
> 2. **3秒破首壳，15秒自动化**：BOSS 第 1 重躯壳仅需点击 3~4 下即可击碎，直接奖励 100 灵石并永久激活【机关傀儡（2次/秒）】购买权（仅售 50 灵石）。

## 一、 主角点击成长底层公式

1. **初始状态**：
   * 主角初始基础攻击力 `baseAtk = 15`。
   * 初始每次点击成长值 `growthPerClick = 2 + (2 * L_rel_c_click_flat)`。
2. **动态累积规则**：
   * 在 `useGameStore` 中维护变量 `accumulatedAtk (Decimal)`（重开时若拥有遗物【逆时沙漏】，则初始值设为 `1000 * (2 ^ L_rel_e_auto_start)`，否则为 `0`）。
   * 每次发生点击（手动、自动傀儡、分身残影）时：
     ```ts
     const currentGrowth = growthPerClick.times(isSkill1Active ? skill1Mult : 1);
     accumulatedAtk = accumulatedAtk.plus(currentGrowth);
     // 若拥有神阶遗物【岁月史书 (rel_m_click_echo)】，同步将 currentGrowth * (0.1 * L) 累加至 SharedHeroGrowth
     ```

## 二、 主角三大养成模块（消耗【灵石】）

### 模块 A：【顿悟】（提升每次点击增加的攻击力 `growthPerClick`）
* **初始等级**：1 级。
* **升级价格公式**：`Cost(L) = 20 * (1.20 ^ (L - 1))` 灵石。
* **每级效果公式**：
  ```ts
  growthPerClick(L) = (2 + 2 * L_rel_c_click_flat) * L * (1.18 ^ (L - 1))
  ```

### 模块 B：【肉身破境】（阶段性质变，达标即可免费点击突破！）

| 境界阶位 | 境界名称 | 达标所需当前灵石 | 达标所需本局点击层数 | 境界总伤害乘数 (`RealmMultiplier`) | 突破额外解锁奖励 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0阶 (初始)| **凡胎肉身** | 0 | 0 | `×1` | 初始自带第1神通：【燃血叩击】（开局满道力可直接释放） |
| 1阶 | **百脉筑基** | `300` | 30 次 (约20秒达成) | `×3` | 解锁第2神通：【万法残影】（分身连打） |
| 2阶 | **煞气金丹** | `8,000` | 200 次 (约2分钟达成)| `×12` | 解锁第3神通：【天罚神雷】（破壳核弹） |
| 3阶 | **不灭元婴** | `300,000` (30万)| 800 次 | `×60` | 解锁第4神通：【弑神共鸣】（全队暴走） |
| 4阶 | **法则化神** | `5.00e7` (5000万)| 2,500 次 | `×400` | 道力上限额外 `+50`，自然恢复 `+2/秒` |
| 5阶~N阶 | **古神道躯·N重**| `5e7 * (500 ^ (N-4))` | 无需点击限制 | 每阶额外 `×10` | 无限破境，中后期质变节点 |

### 模块 C：【机关傀儡】（自动点击器）
* **显示与解锁逻辑（防跨周目卡死）**：
  * 在 `useMetaStore` 中维护永久布尔值 `hasUnlockedPuppet`。一旦玩家在历史任意一局中击破过 Phase 1（或拥有遗物【逆时沙漏】），`hasUnlockedPuppet = true`，此后所有周目开局直接显示购买按钮！
  * 若拥有仙阶遗物【逆时沙漏（等级 `L`）】，则每局开始时**直接免费赠送 `5 * L` 级的机关傀儡**！
* **购买与升级**：
  * **激活价格（1级）**：`50` 灵石。激活后提供基础自动点击：**`2.0 次/秒`**（受遗物【机关发条】加成额外 `+0.2 * L 次/秒`）。
  * **升级价格公式**：`Cost(L) = 50 * (1.18 ^ L)` 灵石（等级上限 60 级）。
  * **攻速成长**：每升 1 级，自动点击频率 **`+0.5 次/秒`**。

## 三、 道力（Mana）与 4 大主动神通系统

### 1. 道力恢复机制
* **容量上限**：`100 + (4 * L_rel_c_mana_cap) + (境界>=4 ? 50 : 0)`。**每局开始时默认拥有满额道力**！
* **双重恢复途径**：
  1. **时间自然恢复**：每秒自动恢复 `1.5` 点道力（化神期后为 `3.5` 点/秒）。
  2. **手操点击回蓝**：玩家**每一次手动点击 BOSS**，额外恢复 **`1.0 + (0.05 * L_rel_c_mana_click)` 点道力**！
