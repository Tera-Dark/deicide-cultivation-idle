# 📖 01. 全局名词解析与 UI 规范 (Glossary & UI - v2.4终极封版)

## 一、 全局简化名词与资源字典
所有 UI 显示与代码变量命名严格遵循以下标准，确保玩家零理解成本：

| 显示名称 | 代码变量名 | 数据类型 | 重开/通关时持久性 | 获取途径与核心用途 |
| :--- | :--- | :--- | :--- | :--- |
| **灵石** | `spiritStones` | `Decimal` | **局内重置 (归零)** | **主货币**。造成伤害即实时获得（无需打死BOSS）。用于提升主角顿悟成长率、升级主动神通、购买机关傀儡及升级佣兵。 |
| **词缀石** | `affixStones` | `number` | **永久保留** | **打造货币**。每击破BOSS的1重躯壳固定掉落；用于洗练佣兵的3个专属词缀。 |
| **神晶** | `divineCrystals` | `Decimal` | **永久保留** | **终局核心货币**。彻底击败BOSS（打穿第10重躯壳）时结算掉落。用于**解锁第2~5号佣兵栏位**、抽取与升级【局外遗物】、锁定极品词缀。 |
| **道力** | `mana` | `number` | **局内重置 (开局满值100)**| **技能能量**。初始上限 100点。每秒自然恢复 `1.5` 点，且**每次手动点击额外恢复 `1.0` 点**。用于释放主角的 4 大主动神通。 |
| **点击层数** | `clickStacks` | `Decimal` | **局内重置 (归零)** | **成长计数**。本局内主角累计有效点击次数（含手动、自动傀儡、分身残影），用于检测肉身破境条件与触发佣兵【伴生】词缀。 |

## 二、 核心重开与传承铁律
1. **主动【重开】**：当玩家因策略失误或遇到瓶颈时，可随时点击顶部【重开】按钮。**中途重开不结算任何【神晶】奖励**，但本局中途打破躯壳已拿到的【词缀石】永久保留！
2. **状态重置范围**：重开或通关进入下一难度时，BOSS血量重置为第1重躯壳、灵石归零（若有先天灵根遗物则重置为初始值）、主角境界/顿悟/神通/傀儡等级归零、当前累积点击修为（`accumulatedAtk`）重置（若有逆时沙漏遗物则设为初始值）、**已解锁佣兵的局内等级（Level）重置为 1 级**。
3. **永久传承范围**：玩家已拥有的【词缀石】、【神晶】、【遗物等级】、**已解锁的佣兵栏位**、**已开启的词缀槽位**，以及 **佣兵栏位上已选择的【基底】和洗出的【3个专属词缀】100% 永久保留！**

## 三、 UI 界面布局与配色规范
* **主题色调**：暗黑修仙克苏鲁风（背景 `#0d0c12`，血条 `#b91c1c`，灵石青 `#06b6d4`，道力蓝 `#3b82f6`，神晶紫 `#a855f7`）。
* **三段式响应式布局**：
  1. **顶部状态栏**：显示当前劫数名称、弑神计时器（`00:00:00.00`）、【重开本局】按钮、【设置/硬重置存档】按钮、三大货币数量。
  2. **中部主战区**：
     - 上方：古神法相（点击触发攻击与飘字）、当前躯壳阶段（`Phase 1~10`）、主血条、实时 DPS 统计条（显示主角、毒伤及各佣兵伤害占比）。
     - 下方快捷栏：**【道力（Mana）进度条】** + **【4个主角主动神通快捷释放图标】**（显示冷却倒计时、持续状态高亮与自动释放勾选框）。
  3. **底部构筑区（4个Tab）**：【主角（肉身破境、顿悟、4大神通升级、机关傀儡）】、【佣兵（5栏位解锁、基底切换、升级与词缀预览洗练）】、【遗物（30件四阶遗物抽取与升级）】、【劫数（10大难度切换与速通榜）】。
