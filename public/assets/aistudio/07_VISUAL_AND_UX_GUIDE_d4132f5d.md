# 🎨 07. 视觉美术风格、SVG古神演变与竖屏交互规范 (Visual, Juice & Mobile UX - v2.6)

> **致 AI 开发者**：本游戏采用**“竖屏手机优先（Mobile-First Portrait）”**布局与**“暗黑修仙 × 克苏鲁神圣几何（Sacred Geometry SVG）”**美术风格。所有图形均使用纯 SVG 多边形 + CSS 发光滤镜（`drop-shadow`）与关键帧动画实现，无需加载任何外部图片资源。

---

## 一、 世界观视觉包装：高维法则几何体
* **设定诠释**：古神并非低维度的血肉怪物，而是盘踞在星空深处的**“高维法则多边形结晶”**。玩家的每一次叩击，都是在用修仙符文轰碎祂的几何法则外壳，直至暴露出最深处的“古神道果核心”。
* **核心色彩规范（Tailwind / Hex）**：
  * 全局深空背景：`#09080d`（带微弱的暗紫色径向渐变 `#161124`）。
  * 卡片与面板背景：`#13111c`（边框 `#2a2438`）。
  * 四大核心色：灵石青 `#06b6d4`、道力蓝 `#3b82f6`、神晶紫 `#a855f7`、古神猩红 `#e11d48`、暴击仙金 `#f59e0b`。

## 二、 竖屏手机优先（Mobile-First）单屏布局规范
* **外层容器限制**：在 PC 浏览器上居中显示为一个手机视口容器（`max-w-[460px] w-full h-[100dvh] mx-auto overflow-hidden flex flex-col border-x border-slate-800 select-none`），禁止整页出现滚动条。
* **黄金三段式高度分配**：
  1. **顶部极简状态栏（约占 `9%` 高度）**：
     * 第 1 行：左侧显示【当前劫数名称按钮】（点击弹出劫数切换与速通记录 Modal）；中间显示 `⏱️ 00:00.0` 计时器；右侧为紧凑的 `🔄重开` 按钮。
     * 第 2 行：均分展示 `💎灵石`、`🔮词缀石`、`✨神晶` 的实时格式化数值。
  2. **中部古神战区与神通栏（约占 `43%` 高度，`relative`）**：
     * **顶部信息**：显示当前躯壳名称（如 `第 3/10 重：畸变触腕`）+ **双层动态血条**（上层鲜红实时扣血，下层暗黄延迟 0.3s 收缩，表现大额扣血爽感！）+ 10个代表躯壳阶段的小圆点指示器 + 当前总 DPS 与毒伤层数。
     * **中央交互区**：居中渲染 **SVG 多边形古神法相**（整个战区背景均可点击触发主角攻击）。古神四周环绕最多 **5 个小型 SVG 佣兵伴飞阵位**。
     * **底部神通快捷栏**：紧贴战区下沿，上方为细长的蓝色【道力条（`100/100`）】，下方横向排列 **4 个主角主动神通圆形/圆角矩形图标**（直观显示 CD 遮罩、激活金边呼吸灯与耗蓝数字，单手大拇指极易点击）。
  3. **底部构筑抽屉区（约占 `48%` 高度，`flex-1 flex flex-col`）**：
     * **精简为 3 大导航 Tab**：`【⚡主角修为】`、`【⚔️五人佣兵】`、`【🏆古神遗物】`（劫数切换已移至顶部标题点击弹窗，减少底部拥挤）。
     * **全局购买倍率胶囊**：在 Tab 栏右侧固定一个紧凑切换器 `[ ×1 | ×10 | MAX ]`，全局控制主角与佣兵的升级购买数量。
     * **内部列表（唯一允许局部滚动的区域 `overflow-y-auto`）**：卡片采用紧凑单行/双行设计，拒绝冗余长文。

## 三、 SVG 古神法相的“10重躯壳阶段演变”设计 (`BossArena.vue`)
随着当前局内 `currentPhase (1 ~ 10)` 的推进，中央的 SVG 古神必须呈现明显的**“外壳剥落、体积缩放与气质演变”**：

1. **Phase 1 ~ 3（外层封印期 —— 幽暗石青色 `#38bdf8`）**：
   * 渲染一个缓慢顺时针旋转的 **最外层正十二边形/八卦符文护盾环** + 内部暗淡的菱形核心。
   * 每破 1 重，外环透明度降低并出现虚线裂纹（`stroke-dasharray`）；打破 Phase 3 时，外环彻底消失！
2. **Phase 4 ~ 6（畸变法相期 —— 邪异紫红色 `#c084fc` -> `#f43f5e`）**：
   * 外环破碎后，暴露出中层的 **双层逆向高速旋转六芒星（由两个交错的 `<polygon>` 三角形构成）**，外围延伸出 6~8 个随呼吸缩放的锐利几何棱刺（代表克苏鲁触腕）。发光滤镜增强。
3. **Phase 7 ~ 9（不朽神躯期 —— 深渊暗金色 `#fbbf24`）**：
   * 几何体整体放大 `1.15倍`，中心睁开一只由多层菱形嵌套构成的 **【克苏鲁几何竖瞳】**，瞳孔随玩家点击轻微收缩，压迫感拉满。
4. **Phase 10（古神道果核心 —— 毁灭猩红与炽白闪烁 `#ef4444`）**：
   * 所有外层装甲全部剥落，只剩下中心一颗剧烈跳动（`animate-pulse` 快速缩放）的 **高维超立方体/八面体核心**，伴随高频能量电弧线条！

## 四、 打击感与动态反馈规范 (Game Feel / Juice)
为确保点击与挂机过程爽快顺眼，必须实现以下 5 项轻量级动效：

1. **BOSS 受击弹性形变与闪白**：
   * 每次受到主角点击或巨炮攻击时，古神 SVG 容器触发 CSS 类：短暂缩放 `scale(0.92)` + 随机偏移 `translate(±3px, ±3px)` + 滤镜增亮 `brightness(1.7)`，持续 `60ms` 后迅速回弹。
2. **点击波纹与伤害飘字池（Floating Text Pool，限制同屏最多 25 个防卡顿）**：
   * 手动点击位置生成一圈扩散淡出的青色 SVG 圆环。
   * 飘字区分样式：普通伤害为白色小字上飘；**暴击伤害**为金色大字 `💥 +数值!` 并带弹跳放大动效；**毒伤结算**为翠绿色数字。
3. **破壳震屏与横幅提示（Phase Break）**：
   * 击破每一重躯壳时，整个战区容器触发 `250ms` 的震屏动画（`@keyframes shake`），BOSS 爆开一圈红色冲击波，顶部浮现醒目提示：`🎉 击破第 X 重躯壳！词缀石 +N`。
4. **5人佣兵的“伴飞几何体”可视化**：
   * 在古神 SVG 四周（或下方弧形排列）渲染已解锁的 1~5 号佣兵微缩几何图标（🗡️飞剑为青色锐角三角形、🐙触手为紫色菱形、☄️巨炮为金色正六边形、☯️阵盘为青金双环）。
   * 当某个佣兵攻击时，其对应的微缩几何体产生一次向 BOSS 冲撞/发射光束的位移动画！
5. **佣兵卡片与【洗词缀独立弹窗（Modal）】简化设计**：
   * 在底部【⚔️五人佣兵】列表中，每张佣兵卡片保持极简（仅一行或紧凑两行）：左侧显示 `[基底图标 + 名称 + Lv.等级 + 逢10级翻倍进度条]`，中间显示 `3个词缀的彩色简写胶囊标签`，右侧直接是宽大的 `【升级 (消耗灵石)】` 按钮。
   * 点击佣兵卡片左侧或词缀标签时，弹出**【佣兵打造与洗练弹窗（Modal）】**：在弹窗内宽敞地展示 4 大基底切换按钮（带流派推荐提示）、3 个词缀槽的详细数值与锁定开关、10抽保底气运进度条（`气运 7/10`）、以及洗练后的**【新旧词缀对比（✅替换 / ❌放弃）】**操作区。
